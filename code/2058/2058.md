# Intuition

A node can only be critical if it has neighbors on both sides, so the list is
scanned with `prev` and `curr`. `get_next` stops at the next critical point and
returns the distance travelled since the previous one.

The first critical point only establishes the starting position. The distance
returned for the second one initializes both answers. After that, every
returned distance is between two consecutive critical points, so the minimum
of these values is the required minimum distance. Their sum is the distance
from the first critical point to the last, which is the maximum distance.

If a second critical point cannot be found, both answers remain `-1`.

The list is traversed once, using `O(n)` time and `O(1)` extra space.
