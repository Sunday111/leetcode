# Intuition

We may reach a cell by several paths, but need not retain a separate account of each. It suffices to record the number of unmatched opening parentheses, provided that no prefix contains more closing than opening parentheses.

Consider the following arrangement:

```text
( )
( (
```

There are two paths to cell `(1, 1)`: `()(` leaves one unmatched opening parenthesis, while `(((` leaves three. A bitset provides a compact record of these possibilities: bit $i$ is set if some valid prefix ending at this cell has $i$ unmatched opening parentheses.

A 128-bit bitset suffices: every unmatched opening parenthesis requires a closing one later, so a valid path's balance cannot exceed half its length. Paths contain fewer than 200 cells; any balance exceeding 127 may therefore be safely discarded.

The transition is the particularly neat part of the arrangement. An opening parenthesis increases every reachable balance by one; a single left shift therefore performs the whole operation. A closing parenthesis requires the corresponding right shift. This also discards bit $0$, precisely as required: a path with no unmatched opening parentheses cannot admit a closing parenthesis.

As entry to a cell is possible from above or from the left, we combine the two predecessor bitsets with bitwise OR before applying the shift. At the destination, it remains only to inspect bit $0$: if set, it confirms that some path has matched every opening parenthesis with a closing one.

# Simple implementation (full state)

The direct arrangement keeps a bitset for every cell. A zero border and a single seed allow the same transition to serve every cell, without separate treatment of the first row or column.

```cpp []
class Solution
{
public:
    bool hasValidPath(const std::vector<std::vector<char>>& g) const noexcept
    {
        const size_t h = g.size();
        const size_t w = g[0].size();
        std::bitset<128> dp[101][101]{};
        dp[0][1] = 1u;
        for (size_t y = 0; y != h; ++y)
        {
            for (size_t x = 0; x != w; ++x)
            {
                auto p = dp[y + 1][x] | dp[y][x + 1];
                if (g[y][x] == '(')
                {
                    dp[y + 1][x + 1] = p << 1;
                }
                else
                {
                    dp[y + 1][x + 1] = p >> 1;
                }
            }
        }
        return dp[h][w][0];
    }
};
```

# Alternating DP rows implementation

Only the current and preceding rows are required. Alternating between two buffers removes the need to retain the whole grid; each reused entry is overwritten before it serves as the left neighbour.

```cpp []
class Solution
{
public:
    bool hasValidPath(const std::vector<std::vector<char>>& g) const noexcept
    {
        const size_t h = g.size();
        const size_t w = g[0].size();
        std::bitset<128> dp[2][101]{};
        dp[0][1] = 1u;
        for (size_t y = 0; y != h; ++y)
        {
            auto& prev = dp[y & 1];
            auto& curr = dp[(y + 1) & 1];
            for (size_t x = 0; x != w; ++x)
            {
                auto p = curr[x] | prev[x + 1];
                if (g[y][x] == '(')
                {
                    curr[x + 1] = p << 1;
                }
                else
                {
                    curr[x + 1] = p >> 1;
                }
            }
        }
        return dp[h & 1][w][0];
    }
};
```

# Minimal state version

One row suffices in turn: when proceeding from left to right, `dp[x]` already holds the current row's left neighbour, while `dp[x + 1]` still holds the preceding row's cell above.

The successive refinements reduced the full table to two rows, then one; a zero border removed the separate boundary cases. Combining predecessors before shifting also replaced two transitions with one, since shifts distribute over bitwise OR. The array selection retains the original transition style.

Before undertaking the DP, we reject impossible endpoints: a valid path must begin with `'('` and end with `')'`. Every path contains $h + w - 1$ cells, so an odd length is likewise impossible: opening and closing parentheses must occur in equal numbers. These checks spare unnecessary work; the DP would otherwise reject the same cases.

```cpp []
class Solution
{
public:
    bool hasValidPath(const std::vector<std::vector<char>>& g) const noexcept
    {
        const size_t w = g[0].size();

        // impossible paths
        if ((g[0][0] == ')') || (g.back().back() == '(')) return false;

        // paths with odd lengths
        if ((g.size() + w - 1) & 1) return false;

        std::bitset<128> dp[101]{};
        dp[1] = 1u;
        for (auto& row : g)
        {
            for (size_t x = 0; x != w; ++x)
            {
                auto p = dp[x] | dp[x + 1];
                dp[x + 1] = std::array{p << 1, p >> 1}[row[x] & 1];
            }
        }
        return dp[w][0];
    }
};
```
