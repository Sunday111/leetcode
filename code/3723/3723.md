# General intuition

It suffices to construct the greatest `n`-digit number with digit sum `s`.
Give each place, from left to right, as much of the remaining sum as it can
hold: take as many nines as the sum permits, then the remainder when nonzero,
and finally zeroes.

This construction also maximises the squared score: concentrating the sum
in larger digits gains more than taking it from smaller digits loses.
It therefore satisfies both requirements—the best score and the greatest
number amongst candidates sharing that score.

If `s > 9 * n`, the prescribed sum exceeds the capacity of the digits.

# Simple Solution

Initialise the string with zeroes, fill the first `q` places with nines,
and assign the remainder digit when present.

```cpp []
class Solution
{
public:
    std::string maxSumOfSquares(size_t n, size_t s) const noexcept
    {
        if (n * 9 < s) return {};
        size_t q = s / 9, rem = s % 9;
        std::string ans(n, '0');
        std::fill(ans.begin(), ans.begin() + q, '9');
        if (rem) ans[q] = static_cast<char>('0' + rem);
        return ans;
    }
};
```

# Choosing the initial fill

The ordinary `std::string` constructor initialises every character; it offers
no option to leave them uninitialised. Since this first pass is required by
that construction, I choose its fill character to shorten the second pass.

There are `q = s / 9` nines and `n - q - !!rem` zeroes, where
`rem = s % 9`. If the nines are fewer, initialise with zeroes and overwrite
only the prefix. Otherwise, initialise with nines and overwrite only the
zero suffix. The remainder digit, when present, is assigned separately.
Thus the second fill visits the smaller of the two runs.

```cpp []
class Solution
{
public:
    std::string maxSumOfSquares(size_t n, size_t s) const noexcept
    {
        if (n * 9 < s) return {};

        size_t q = s / 9;
        size_t rem = s % 9;
        bool fill_nines = q <= n - q - !!rem;
        std::string ans(n, fill_nines ? '0' : '9');
        if (fill_nines)
        {
            std::ranges::fill(ans | std::views::take(q), '9');
        }
        else
        {
            std::ranges::fill(ans | std::views::drop(q + !!rem), '0');
        }
        if (rem)
        {
            ans[q] = static_cast<char>('0' + rem);
        }
        return ans;
    }
};
```

# Ranges solution

The construction requires three runs: `q = s / 9` nines, a single remainder
digit `rem = s % 9` when nonzero (`t = !!rem`), and sufficient zeroes to complete
the prescribed `n` digits.

```cpp []
class Solution
{
public:
    std::string maxSumOfSquares(size_t n, size_t s) const noexcept
    {
        if (n * 9 < s) return {};
        using std::views::repeat;
        const size_t q = s / 9, rem = s % 9, t = !!rem;
        const char tc = static_cast<char>('0' + rem);
        return std::array{
                   repeat('9', q),
                   repeat(tc, t),
                   repeat('0', n - q - t)} |
               std::views::join | std::ranges::to<std::string>();
    }
};
```

- `repeat(value, count)` specifies each run; its characters are supplied only
  as required, with no intermediate string.
- `std::array{...}` arranges the three runs in their proper order. A run of
  length zero contributes nothing.
- `views::join` presents these runs as one continuous sequence of characters.
- `ranges::to<std::string>()` gathers that sequence into the finished string.

Thus, with `n = 5` and `s = 20`, the runs are `"99"`, `"2"`, and `"00"`;
their assembly yields `"99200"`.
