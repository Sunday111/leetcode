# General intuition

It suffices to construct the greatest `num`-digit number with digit sum `s`.
Give each place, from left to right, as much of the remaining sum as it can
hold: take as many nines as the sum permits, then the remainder when nonzero,
and finally zeroes.

This construction also maximises the squared score: concentrating the sum
in larger digits gains more than taking it from smaller digits loses.
It therefore satisfies both requirements—the best score and the greatest
number amongst candidates sharing that score.

If `s > 9 * num`, the prescribed sum exceeds the capacity of the digits.

# Ranges intuition

The construction requires three runs: `q = s / 9` nines, a single remainder
digit `r = s % 9` when nonzero (`t = !!r`), and sufficient zeroes to complete
the prescribed `num` digits.

```cpp
#include <ranges>
#include <string>

#include "sync_stdio.hpp"

class Solution
{
public:
    std::string maxSumOfSquares(size_t num, size_t s) const noexcept
    {
        if (num * 9 < s) return {};
        using std::views::repeat;
        const size_t q = s / 9, r = s % 9, t = !!r;
        const char tc = static_cast<char>('0' + r);
        return std::array{
                   repeat('9', q),
                   repeat(tc, t),
                   repeat('0', num - q - t)} |
               std::views::join | std::ranges::to<std::string>();
    }
};
```

- `repeat(value, count)` specifies each run; its characters are supplied only
  as required, with no intermediate string.
- `std::array{...}` arranges the three runs in their proper order. A run of
  length zero contributes nothing.
- `views::join` presents these runs as one continuous sequence of characters.
- `ranges::to<std::string>()` gathers that sequence into the finished string.

Thus, with `num = 5` and `s = 20`, the runs are `"99"`, `"2"`, and `"00"`;
their assembly yields `"99200"`.
